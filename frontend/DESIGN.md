## 1. Философия

Аналитика для руководителя медцентра. **Белые карточки на голубоватом фоне**,
крупные жирные цифры, один бренд-акцент — синий `#328FCD`.

1. Данные — главное. Цифры крупные (800), подписи мелкие и тихие.
2. Иерархия через размер и насыщенность шрифта, а не через рамки.
3. Цвет — только для смысла: бренд (активное/действие), зелёный/красный/жёлтый (статусы).

|--------------------------|-----------|------------------------------------------------|
| `bg-background`          | `#f1f7fc` | Фон контентной области                          |

| `border-border`          | `#d6e8f5` | Рамки контролов, разделители шапки/сайдбара    |
| `border-hairline`        | `#e8f2f9` | Разделители внутри карточек и таблиц           |

### Бренд

| Токен                    | Значение  | Где                                            |
|--------------------------|-----------|------------------------------------------------|
| `bg-brand`               | `#328FCD` | Активный пункт меню, пилюля периода, основная кнопка |

| `bg-brand-soft`          | `#e6f3fb` | Подложка иконок/аватаров                        |

### Статусы

Палитра Tailwind `emerald / red / amber / blue` **переопределена** в `globals.css`
под цвета макета (`#1a9e6e`, `#e03a5a`, `#e09020`, `#328FCD`). Поэтому пишем привычно:

```
Зелёный  — норма, рост хорошего:   text-emerald-600 dark:text-emerald-400
Красный  — тревога, потери:        text-red-600 dark:text-red-400
Жёлтый   — внимание, пограничное:  text-amber-600 dark:text-amber-400
Синий    — нейтральная инфо:       text-blue-600 dark:text-blue-400
Фиолетовый — только «новые пациенты» (5-я серия)
```

Бейдж-дельта: `rounded-[5px] px-1.5 py-0.5 text-[11px] font-bold bg-{цвет}-500/10 text-{цвет}-600`.
Готовые: `<Delta>`, `<StatusPill>` из `components/ui/primitives.tsx`, классы `.pill-green` и т.д.

### Графики

```
chart-1 — #328FCD бренд (основной ряд)
chart-2 — #1a9e6e зелёный (принятые, явки)
chart-3 — #e03a5a красный (пропущенные, неявки)
chart-4 — #e09020 жёлтый (сравнение, предыдущий период)
chart-5 — #8b5cf6 фиолетовый (редко)
```
В Recharts можно передавать hex этих цветов напрямую (SVG-атрибуты не понимают `var()`).

## 3. Типографика

Шрифт **Montserrat** (next/font, кириллица), базовый размер 13px.

| Уровень             | Классы                                                                  |
|---------------------|-------------------------------------------------------------------------|
| Заголовок в шапке   | `text-[14px] font-bold tracking-[-0.02em]`                              |
| Заголовок карточки  | `.section-title` → `text-[13px] font-bold`                              |
| Метка карточки      | `.metric-label` → `text-[10.5px] font-semibold uppercase tracking-[.07em] text-text-3` |
| Значение метрики    | `text-[30px] font-extrabold leading-none tracking-[-0.04em] tabular-nums` (крупная KPI — 36px) |
| Подпись под цифрой  | `text-[11px] text-text-3`                                               |
| Ячейка таблицы      | `text-[12px]`, заголовок колонки `text-[10px] font-bold uppercase tracking-[.06em] text-text-3` |

Числа — всегда `tabular-nums`.

## 5. Компоненты

Всё базовое — в `components/ui/primitives.tsx`. Новые страницы собираются из них.

### Карточка

```tsx
<div className="card-surface p-5">…</div>   // белая, radius 12px, мягкая тень, без рамки
```
- `card-surface` = `rounded-lg bg-card` + `--card-shadow`; в тёмной теме — тонкая рамка `hairline`.
- Старая разметка `rounded-lg border border-border bg-card` автоматически получает тот же вид.
- shadcn `<Card>` уже использует `card-surface`.
- Нельзя: `shadow-lg/xl`, `rounded-2xl`, цветные рамки у карточек.

### MetricCard (KPI)

`<MetricCard label value sub deltaDir deltaPct icon iconTone planPct />`
— метка сверху, цифра 30px/800, подпись, бейдж-дельта. С `icon` — иконка 36×36 в
цветной подложке слева сверху и дельта справа, как на главной в макете.

### Шапка страницы

- `<Topbar>` — для страниц с периодом: заголовок, `filterLabel` + `filterMenu`,
  `periodItems` (пилюля-дропдаун), `periodLabel` + стрелки, обновление.
- Для нестандартных шапок: `<PageHeader title>` + `<PeriodPill>`, `<DateNav>`,
  `<HeaderDivider>`, `<RefreshButton>`, `<FilterButton>`.
- Выпадающие списки: `<MenuPanel>`, `<MenuItem active>`, `<MenuLabel>`, `<MenuDivider>`
  (активный пункт — точка и цвет бренда).

### Переключатели

- **Период** — только `<PeriodPill>` (бренд-кнопка с меню), не ряд табов.
- **Вкладки внутри страницы** — `<TabGroup>`: чипы `rounded-full`, активный — `bg-foreground text-background`.
- **Месяцы** (Планы) — мелкие `rounded-[5px]`, активный — `bg-brand`.

### Кнопки

| Вид          | Классы                                                                 |
|--------------|------------------------------------------------------------------------|
| Основная     | `h-7..9 rounded-[7px] bg-brand text-brand-foreground hover:bg-brand-strong font-semibold` |
| Вторичная    | `rounded-[7px] border border-border bg-card text-text-2 hover:bg-accent` |
| Иконка       | `h-7 w-7 rounded-[7px] text-text-3 hover:bg-accent` + `aria-label`      |

### Таблицы

- `<Th>` / `<Td>`; разделители `border-hairline`, без зебры.
- Выходные/неактивные строки — `text-text-3`.
- Hover строки — `hover:bg-accent/60`.

### Иконки

Lucide React, 16px в навигации (`strokeWidth 1.6`), 12–14px в контролах.
Без эмодзи.

## 6. Сайдбар

- Сворачиваемый: **56px** (только иконки, подсказки через `title`) ↔ **220px**.
  Переключается кликом по логотипу, состояние в `localStorage` (`pulse.sidebar.expanded`).
- Логотип: квадрат 26px `bg-brand` с иконкой пульса + «Пульс».
- Активный пункт: `bg-brand text-brand-foreground`; остальные `text-text-3 hover:bg-accent`.
- Внизу: переключатель темы и блок пользователя (инициалы, имя, роль).
- Показываются только разделы, доступные пользователю (`canSee`).
- Новый раздел: добавить в `SECTIONS` (`sidebar.tsx`) и в `Section` (`lib/permissions.ts`).

## 7. Тёмная тема

Обязательна. Тёмная палитра — глубокий navy (`#0b1724` фон, `#112131` карточки)
в той же гамме, бренд светлее (`#4aa3e0`). Использовать токены — тогда тема
работает сама. Для цветных текстов — пары `-600 / dark:-400`.

Нельзя: `text-white`, `bg-white`, `text-black` — только токены (`text-brand-foreground` на бренде).

## 9a. Главная: виджеты

Главная собирается пользователем из виджетов на сетке 12 колонок (`components/home-dashboard.tsx`).

- Типы, размеры, группы и права — `lib/grid.ts` (`WIDGET_TYPES`), раскладка по умолчанию — `DEFAULT_LAYOUT`.
- Строка сетки фиксированной высоты `ROW_H = 76px`, промежуток `GAP = 14px`; уже 720px сетка становится колонкой.
- Компонент и настройки каждого типа — `components/widgets/registry.tsx`; оболочка — `widgets/widget-card.tsx`
  (`WidgetCard`, `WidgetHeader`, `DeltaBadge`, `WidgetSkeleton`, `WidgetEmpty`).
- Виджет занимает всю высоту ячейки (`h-full`), длинный список скроллится внутри; узкие раскладки — через container queries (`@container`, `@[26rem]:…`).
- Каталог рисует настоящие виджеты на демо-данных (`lib/home-sample.ts`), поэтому превью всегда совпадает с главной.
- Раскладка хранится в `localStorage` (`grid_layout_v2`) у каждого пользователя; виджеты без права на раздел не показываются.
- Группы каталога совпадают с разделами сайдбара: Звонки, Записи, Пациенты, Выручка, Врачи, Воронка, Планы, Отчёты.
- Каждый тип объявляет `data` — какие данные ему нужны (`DataKey` в `lib/home-data.ts`); главная запрашивает только то, что стоит на экране.
- Новый виджет: тип в `WIDGET_TYPES` (с `data` и `permission`), компонент в `widgets/`, ветка в `WidgetContent`, демо-данные в `home-sample.ts`, при выборе метрики — запись в `WIDGET_OPTIONS`.

## 10. Запрещено

❌ Ряд табов для выбора периода (только `PeriodPill`)
❌ Рамки и тяжёлые тени у карточек данных, `rounded-2xl+`
❌ Hex/oklch в className (кроме цветов серий в графиках)
❌ Новые акцентные цвета вне палитры; градиенты-«украшения»
❌ Интерактив на `div`/`span` — только `<button>`, `<a>`, `<input>` + `<label>`
❌ Иконочные кнопки без `aria-label`
❌ Анимации кроме переходов состояний и `animate-pulse` скелетонов
